# About CMIP7

## CMIP: The Coupled Model Intercomparison Project

The Coupled Model Intercomparison Project (CMIP) is a global initiative to deliver climate assessments to the Intergovernmental Panel on Climate Change (IPCC). Coordinated by the World Climate Research Programme (WCRP), international modelling centres run a standardised set of experiments using their own models with standard input data and protocols for such things as greenhouse gas concentrations, aerosols and land use. They then publish their results in a standard format through the Earth System Grid Federation (ESGF), including the NCI. The results of these experiments can then be compared directly to assess how well they reproduce the observed climate and to quantify uncertainty in future projections.

## CMIP7

The current phase of the project is the seventh assessment, CMIP7. It specifies a core set of baseline experiments that each modelling centre should run, including a pre-industrial control, idealised CO~2~ changes, and historical simulations, plus optional experiments that address a variety of scientific questions. The ACCESS Consortium is currently delivering to the CMIP7 Fast Track, a prioritised set of experiments to inform the IPCC's Seventh Assessment Report.

??? info "The four fundamental questions CMIP7 will address"
    [Dunne et al. (2025)](https://gmd.copernicus.org/articles/18/6671/2025/) identify four fundamental questions that CMIP7 will address:

    1. What are the patterns of sea surface change and the implications for cloud feedbacks and the global temperature response to increasing greenhouse gas concentrations?
    2. How will weather extremes respond to climate change?
    3. How does the carbon cycle feed back onto a changing climate?
    4. What are the risks of tipping points where the climate system changes abruptly or irreversibly?
