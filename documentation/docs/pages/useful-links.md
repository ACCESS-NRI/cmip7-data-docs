# Useful links

This page brings together external websites that are useful when working with CMIP7 data in Australia, including the sites most often linked from this guide.

## CMIP7 guidance and standards

- **[WCRP CMIP7 Guidance for data users](https://wcrp-cmip.github.io/cmip7-guidance/docs/CMIP7/Guidance_for_users/)**: the official guide to finding, understanding and using CMIP7 data, from the World Climate Research Programme (WCRP). Most of the information in this guide comes from, or is linked from, here.
- **[CMIP7 experiment setup and forcings](https://wcrp-cmip.github.io/cmip7-guidance/docs/CMIP7/Experiment_set_up_and_Forcings/)**: descriptions of every CMIP7 experiment, with links to the scientific papers describing them.
- **[CMIP7 global attributes, filenames and folder structure](https://wcrp-cmip.github.io/cmip7-guidance/docs/CMIP7/Global_Attributes/)**: the labels used to describe CMIP7 data (the Data Reference Syntax), including what has changed since CMIP6.
- **[CMIP7 variables table](https://cmip-data-request.github.io/cmip7-dreq-webview/latest/variables.html)**: a searchable list of every variable requested for CMIP7, which you can search by CMIP7 or CMIP6 name.
- **[ESGF Errata Service](https://errata.esgf.io/)**: search for and report known issues in published CMIP data.
- **[CF conventions](https://cfconventions.org/)**: the conventions that define how NetCDF files describe coordinates, units and standard names.

## Finding and accessing CMIP7 data

- **[ACCESS-NRI Interactive Data Catalogue](https://access-nri.github.io/interactive-data-catalogue/)**: a web-based catalogue to search the CMIP7 data held on NCI, with ready-to-run Python code to load it.
- **[ACCESS-NRI Intake catalogue](https://access-nri-intake-catalog.readthedocs.io/en/latest/)**: a Python tool to search for and load data on NCI without needing to know where the files are.
- **[ESGF MetaGrid (NCI)](https://esgf.nci.org.au/search)**: the web interface for searching and downloading data from the global CMIP7 archive on the Earth System Grid Federation (ESGF).
- **[Climate Resource CMIP7 availability dashboard](https://www.climate-resource.com/tools/esm-model/cmip7-availability)**: tracks how much of the requested CMIP7 data each modelling centre has published so far.

## NCI

- **[NCI user documentation](https://opus.nci.org.au/)**: NCI's help pages, covering accounts, logging in to Gadi and running jobs.
- **[MyNCI](https://my.nci.org.au/)**: manage your NCI account and request to join projects.
- **[Australian Research Environment (ARE)](https://are.nci.org.au)**: NCI's web-based platform for running JupyterLab and other interactive sessions on Gadi.

## ACCESS-NRI and the ACCESS community

- **[ACCESS CMIP7 dashboard](https://access-nri.github.io/cmip7-dashboard/)**: the status of Australian ACCESS model runs for CMIP7.
- **[ACCESS-NRI CMIP7 overview](https://www.access-nri.org.au/cmip7-overview/)**: ACCESS-NRI's summary of Australia's contribution to CMIP7.
- **[ACCESS-Hive Docs](https://docs.access-hive.org.au/)**: community documentation for ACCESS models and tools, including guides to ARE and model evaluation on Gadi.
- **[ACCESS-Hive Forum](https://forum.access-hive.org.au/)**: the place to ask questions and get help from ACCESS-NRI and the community.
- **[ACCESS-MOPPy](https://access-moppy.readthedocs.io/en/latest/)**: the tool used to turn ACCESS model output into CMIP7-compliant files.

## Evaluating CMIP7 data

- **[ESMValTool](https://docs.esmvaltool.org/)**: a community tool for evaluating and analysing climate model output, using reusable *recipes*.
- **[CMIP Rapid Evaluation Framework (REF)](https://www.wcrp-cmip.org/cmip-phases/cmip7/rapid-evaluation-framework/)**: an international effort to run standard diagnostics on CMIP7 models as data is published. Browse its results on the [CMIP7 diagnostics dashboard](https://dashboard.climate-ref.org/diagnostics?mip_era=CMIP7&view=cards).
- **[ILAMB](https://www.ilamb.org/)**: compares modelled land processes, such as the carbon and water cycles, with observations.

## Australian climate information and regional projections

- **[Climate Change in Australia](https://www.climatechangeinaustralia.gov.au/)**: climate projections, information, tools and data for Australia, based on global climate models including CMIP models.
- **[Australian Climate Service](https://www.acs.gov.au/)**: a partnership of the Bureau of Meteorology, CSIRO, Geoscience Australia and the Australian Bureau of Statistics, providing information and data on climate and natural hazard risks.
- **[NARCliM](https://www.climatechange.environment.nsw.gov.au/narclim)**: the NSW and Australian Regional Climate Modelling project, which produces high-resolution regional climate projections for NSW and Australia. Download NARCliM data from the [NSW Climate Data Portal](https://www.climatechange.environment.nsw.gov.au/climate-data-portal).
- **[CORDEX-Australasia](https://cordex.org/domains/region-9-australasia/)**: the Australasian region of the Coordinated Regional Climate Downscaling Experiment (CORDEX), which downscales global climate models to higher resolution for Australia, New Zealand and nearby regions.

## CMIP and the IPCC

- **[IPCC AR6 Working Group I, Chapter 1: Framing, Context and Methods](https://www.ipcc.ch/report/ar6/wg1/chapter/chapter-1/)**: explains how the IPCC's Sixth Assessment Report uses climate models, including the CMIP6 and CORDEX model intercomparisons.
