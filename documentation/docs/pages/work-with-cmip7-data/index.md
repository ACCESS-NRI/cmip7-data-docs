# Work with CMIP7 data

Once you have the CMIP7 data you need, this section helps you use it in your research. It covers tools to explore and evaluate CMIP7 data, and how to cite the data and check for known issues.

??? tip "Haven't found your data yet?"
    See [Find CMIP7 data](../find-cmip7-data/index.md) to check what CMIP7 data is available and how to access it, with or without an NCI account.

??? tip "Working on NCI? Get set up first"
    Most of the tools in this section work best on NCI's Gadi supercomputer, where much of the CMIP7 data is already stored. If you haven't yet, [set up an NCI account](../get-set-up-nci/set-up-account.md) and [join the CMIP7 projects](../get-set-up-nci/join-projects.md).
