# Find CMIP7 data

This section helps you find the CMIP7 data you need for your research. It covers what CMIP7 data is available on NCI and internationally, and the different ways to find and access it, with or without an NCI account.

??? tip "Working on NCI? Get set up first"
    A lot of CMIP7 data is already stored on NCI's Gadi supercomputer, so you can work with it without downloading anything. To use it there, you'll need to [set up an NCI account](../get-set-up-nci/set-up-account.md) and [join the CMIP7 projects](../get-set-up-nci/join-projects.md). You don't need an NCI account for every access method, though.

??? tip "New to CMIP7 data?"
    CMIP7 search tools filter data using a common set of labels, such as experiment, model, variable and frequency. [CMIP7 experiments and data standards](../about-cmip7/experiments-data-standards.md) explains what these mean.
