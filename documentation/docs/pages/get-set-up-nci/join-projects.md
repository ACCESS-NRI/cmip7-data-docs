# Join CMIP7 projects

On NCI, access to data and software is managed through projects. You need to join a project before you can read the data or use the software it holds. Each project has a short code, such as `xp65`.

## How to join NCI projects

??? info "How to join NCI projects"
    To request membership, search for the project code on [MyNCI](https://my.nci.org.au/mancini/project-search). For step-by-step instructions, see the ACCESS-Hive Docs guide to [joining NCI projects](https://docs.access-hive.org.au/getting_started/set_up_nci_account/#join-relevant-nci-projects).

    !!! warning
        Each request is approved by that project's lead, so **approval may take 1-2 business days**.

## List of CMIP-related projects

??? info "CMIP7 projects"
    ### CMIP7 projects
    | Project | What it gives you | Who needs it |
    |---|---|---|
    | `[CMIP7 replica project]` | CMIP7 data from international modelling centres, replicated to NCI | Everyone working with CMIP7 data |
    | `[Australian CMIP7 project]` | CMIP7 data published by Australian modelling groups, including ACCESS models | Everyone working with CMIP7 data |
    | `xp65` | ACCESS-NRI's analysis software environment, a ready-to-use Python environment with common climate analysis packages (see [conda/analysis3 environment](https://docs.access-hive.org.au/getting_started/environments/)) | Recommended for anyone analysing data on Gadi |

??? info "CMIP6 projects"
    ### CMIP6 projects
    If you want to compare CMIP7 with the previous phase, you can also join the CMIP6 projects.

    | Project | What it gives you |
    |---|---|
    | `oi10` | CMIP6 data from international modelling centres, replicated to NCI |
    | `fs38` | CMIP6 data published by Australian modelling groups |
