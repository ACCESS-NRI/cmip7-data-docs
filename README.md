# CMIP7 Data Docs

Source for the [CMIP7 Data Documentation in Australia website](https://cmip7-data-docs.readthedocs.io), the guide to finding, accessing, understanding, using, and publishing CMIP7 climate model data on NCI.

Jointly created and maintained by NCI and ACCESS-NRI.

## Contributing

Open an issue or pull request, or use the "Edit this page" button on any page of the site. A website preview is generated for each pull request created or updated. Changes to `main` are published automatically to the live site via the Read the Docs hosting platform.


## Build locally

```bash
pip install -r requirements.txt
mkdocs serve
```

Then open http://127.0.0.1:8000. Pages live in `docs/`, and navigation is set in `mkdocs.yml`.
